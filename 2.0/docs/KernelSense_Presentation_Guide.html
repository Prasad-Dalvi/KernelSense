Slide 2 / 11 • Problem Statement & Objective

Problem Statement & Core Objectives

  • Reactive Troubleshooting: Sysadmins intervene only after runaway memory leaks crash production servers.
  • Opaque Error Streams: Thousands of raw kernel logs without automated causal correlation.
  • Static Threshold Limitations: Fixed 80% CPU alerts cause constant false alarms under normal burst compute.
  • Slow CLI Lookups: Finding IP addresses, user identities, or local documents requires tedious manual digging.
🎙️ Speaker Note: Explain that modern OS observability is reactive and noisy. KernelSense replaces static thresholds with multi-variate ML intelligence.
Slide 3 / 11 • Proposed Solution

KernelSense: Autonomous AI-Powered OS Copilot

  • Live Telemetry & Isolation Forest: Ingests 11 hardware streams (<15ms TTL caching) to output a 0-100% dynamic Anomaly Score.
  • Universal ReAct AI Agent (Llama 3.2): Local offline reasoning in Ubuntu WSL2 + Cloud API acceleration with grounded telemetry RAG.
  • Core Linux & OS Command Engine: Plain-language translation into exact shell commands (IP discovery, Whoami, lscpu, ss -tuln).
  • Multi-Drive File Discovery (<8ms): Instant bounded search across all drives (C:, D:) with one-click desktop app launching.
🎙️ Speaker Note: Highlight the 4 pillars: Unsupervised ML, Local Llama 3.2 LLM reasoning, Core Linux intelligence, and High-speed local file discovery.

Slide 7 / 11 • Security & Safety

Multi-Layered Security & Safe Execution Framework

  • Layer 1: Automated Command Risk Classifier (Regex & heuristic pattern scoring into LOW, MEDIUM, HIGH risk).
  • Layer 2: Destructive Command Blocking (Intercepts rm -rf /, format, mkfs.ext4, fork-bombs).
  • Layer 3: Human-in-the-Loop Approval Gateway (Mandatory operator approval with unique cryptographic UUIDs).
  • Layer 4: Sandboxed Execution & Immutable SQLite Audit Trail (Enforces execution timeouts and logs all executions with timestamps).
🎙️ Speaker Note: Safety is paramount. AI never executes unchecked destructive commands. Operators always maintain ultimate control.
